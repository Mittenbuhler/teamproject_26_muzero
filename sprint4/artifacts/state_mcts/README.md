# Modular MCTS testbed: reports and historical comparisons

These artifacts belong to the retained [component-testing version](../../state_mcts/README.md).
They are separate from the final CartPole and MinAtar MuZero result folders.

`state_mcts_report.json` holds test runs; `value_mcts_action_diagnostic.json`
holds value/action diagnostics. The numbered comparison images are historical
snapshots of changing value targets and bootstrap settings, not current MuZero
performance claims. Existing data stays in place.

Rebuild the dashboard or start a new test using [central commands](../../COMMANDS.md).
Inspect each report's settings before comparing scores from different runs.
